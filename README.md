# AI Interview Assistant

A backend service for practicing technical interviews. Users register/login
with JWT-based authentication, request a mock interview for a given role and
difficulty (questions are generated by Claude AI), submit written answers, and
receive an AI-generated scorecard with an overall score and per-question feedback.

## Tech Stack

- **Java 17 / Spring Boot 3** — REST API
- **Spring Security + JWT** (jjwt 0.11.5) — stateless authentication
- **Spring Data JPA + Hibernate** — ORM and persistence
- **PostgreSQL** — relational database
- **Anthropic Claude API** — AI question generation and answer evaluation
- **Maven**

## Architecture

```
Client
  │  Authorization: Bearer <JWT>
  ▼
JwtAuthFilter ──► SecurityContextHolder
  │
  ▼
Controllers  (AuthController / InterviewController / ScorecardController)
  │
  ▼
Services     (AuthService / InterviewService / ScorecardService)
  │                │
  │                ▼
  │          AiService (AnthropicAiService) ──► Claude API
  │
  ▼
Repositories (Spring Data JPA) ──► PostgreSQL
```

### Entity relationships
```
User ──< Interview ──< Question ──── Answer
                  └──── Scorecard
```

## Setup

### 1. Prerequisites
- Java 17+
- Maven 3.8+
- PostgreSQL running locally
- An Anthropic API key from https://console.anthropic.com/

### 2. Create the PostgreSQL database

```bash
sudo -u postgres psql
```

```sql
CREATE DATABASE ai_interview_db;
CREATE USER ai_interview_user WITH PASSWORD 'your_password_here';
GRANT ALL PRIVILEGES ON DATABASE ai_interview_db TO ai_interview_user;
\q
```

### 3. Set environment variables

```bash
export DB_USERNAME=your_db_username
export DB_PASSWORD=your_db_password
export JWT_SECRET=your_jwt_secret
export ANTHROPIC_API_KEY=your_anthropic_api_key
```

### 4. Run the application

```bash
mvn spring-boot:run
```

The app starts on `http://localhost:8080`. Hibernate will auto-create all
tables on first run (`ddl-auto: update`).

To verify tables were created:
```bash
psql -U ai_interview_user -d ai_interview_db -h localhost -c "\dt"
```

You should see: `users`, `interviews`, `questions`, `answers`, `scorecards`.

## API Reference

All endpoints except `/api/auth/**` require:
`Authorization: Bearer <token>`

### Auth

| Method | Endpoint             | Body fields                          | Returns     |
|--------|----------------------|--------------------------------------|-------------|
| POST   | `/api/auth/register` | username, email, password            | token + username |
| POST   | `/api/auth/login`    | username, password                   | token + username |

**Register**
```bash
curl -X POST http://localhost:8080/api/auth/register \
  -H "Content-Type: application/json" \
  -d '{"username":"vaishnavi","email":"vaishnavi@example.com","password":"password123"}'
```

**Login**
```bash
curl -X POST http://localhost:8080/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"vaishnavi","password":"password123"}'
```

Both return:
```json
{
  "token": "eyJhbGciOiJIUzI1NiJ9...",
  "username": "vaishnavi",
  "tokenType": "Bearer"
}
```

Save the token: `export TOKEN=eyJhbGciOiJIUzI1NiJ9...`

### Interviews

| Method | Endpoint                                              | Description                           |
|--------|-------------------------------------------------------|---------------------------------------|
| POST   | `/api/interviews`                                     | Create interview (AI generates Qs)    |
| GET    | `/api/interviews`                                     | List your interview history           |
| GET    | `/api/interviews/{id}`                                | Get interview detail + answers so far |
| POST   | `/api/interviews/{id}/questions/{questionId}/answer`  | Submit/update an answer               |

**Create interview** — difficulty options: `EASY`, `MEDIUM`, `HARD`
```bash
curl -X POST http://localhost:8080/api/interviews \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"role":"Backend Developer - Java","difficulty":"MEDIUM","numberOfQuestions":5}'
```

**Submit an answer**
```bash
curl -X POST http://localhost:8080/api/interviews/1/questions/3/answer \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"answerText":"I would add an index on the foreign key column and rewrite the subquery as a JOIN..."}'
```

### Scorecard

| Method | Endpoint                        | Description                               |
|--------|---------------------------------|-------------------------------------------|
| POST   | `/api/interviews/{id}/scorecard` | Trigger AI evaluation, generate scorecard |
| GET    | `/api/interviews/{id}/scorecard` | Get a previously generated scorecard      |

**Generate scorecard** (call this after submitting answers)
```bash
curl -X POST http://localhost:8080/api/interviews/1/scorecard \
  -H "Authorization: Bearer $TOKEN"
```

**Response**
```json
{
  "interviewId": 1,
  "overallScore": 78.5,
  "strengths": "Strong understanding of REST principles and SQL indexing strategies...",
  "weaknesses": "Could go deeper on distributed transaction handling and caching trade-offs...",
  "feedback": [
    {
      "questionId": 3,
      "questionText": "How would you optimize a slow SQL query?",
      "comment": "Good mention of indexing but missed EXPLAIN ANALYZE and query plan inspection.",
      "score": 7.5
    }
  ],
  "generatedAt": "2026-06-14T10:15:30"
}
```

## Interview flow (end to end)

1. `POST /api/auth/register` → get token
2. `POST /api/interviews` with role + difficulty → get interview ID + questions
3. `POST /api/interviews/{id}/questions/{questionId}/answer` for each question
4. `POST /api/interviews/{id}/scorecard` → get AI evaluation
5. `GET /api/interviews` → view full history
